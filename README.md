## Overview

This project is a classic Snake Game where the player controls a snake to collect food and grow in size. The game ends when the snake collides with itself or the walls.

## Features

- Dynamic grid-based gameplay.
- Randomly generated food with unique colors.
- Score tracking.
- Game over screen with retry functionality.
- Responsive design for different screen sizes.

## Project Structure

```
index.html
assets/
    audio.mp3
css/
    index.css
js/
    index.js
```

- **index.html**: The main HTML file that structures the game.
- **assets/audio.mp3**: Background sound effect for eating food.
- **css/index.css**: Styles for the game, including the menu, score display, and canvas.
- **js/index.js**: Core game logic, including snake movement, food generation, collision detection, and game loop.

## How to Play

1. Use the arrow keys (`↑`, `↓`, `←`, `→`) to control the snake's direction.
2. Collect the food to increase your score and grow the snake.
3. Avoid colliding with the walls or the snake's own body.
4. When the game ends, click the "Retry" button to play again.

## How to Run

1. Clone this repository or download the project files.
2. Open the `index.html` file in any modern web browser.
3. Start playing the game!

## Technologies Used
